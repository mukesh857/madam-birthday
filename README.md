# 🎂 Happy Birthday Neha Mam

A premium interactive birthday website made with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will give you the live website URL.

## Optional birthday music
Put an MP3 file named `birthday.mp3` inside `assets/`, then change the audio element in `index.html` to:

```html
<audio id="music" loop preload="auto" src="assets/birthday.mp3"></audio>
```

Use music you have permission to publish.
